# Support

Use GitHub issues for reproducible, non-sensitive bugs and documentation problems in the supported
package. Include the version, operating system, Python version, expected behavior, and a minimal
reproducer with placeholder configuration.

- General and licensing questions: contact@samsarix.com
- Installation and product support: support@samsarix.com
- Suspected vulnerabilities: follow [SECURITY.md](SECURITY.md)

Never include Discord tokens, private endpoint URLs, response bodies, personal data, or exploit
details in a public issue. The open-source license does not include a support SLA.
